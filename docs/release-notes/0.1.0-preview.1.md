# Norn 0.1.0-preview.1

6 September 2026, Melbourne time. Local development preview; this note does not declare a public release or a completed venue battery.

This preview keeps the full-screen renderer while restoring the original conversation and composer styling: blue user prefixes, assistant prose, and composer divider lines with status/model details. Tool calls use compact descriptions, with original output and recorded changes available on demand. Internal provider provenance, response identifiers and token-estimation events remain available as metadata rather than ordinary conversation text.

The retained conversation binds live output to its accepted record so prompts and answers appear once. Chronological event-gap ordering keeps later accepted messages after earlier local notices. Deferred mouse-event batches retain detail-load requests until the selected frame is ready.

The existing Astra model selection and MCP Channels/settings support remain included. Iridium is not yet embedded; live attach/detach, editable workspace panels and preferences that persist across restarts remain separate unfinished work.

Each installed preview has a unique prerelease version, an artifact hash, a local verification receipt and a verified rollback binary. Later previews increment the prerelease number. The first stable release is 0.1.0 after its release requirements pass. Installation announcements say “Norn updated” only after the installed version and hash are verified. Local preview installation is not a main-branch landing or public release.
