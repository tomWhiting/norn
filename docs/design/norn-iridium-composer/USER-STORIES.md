# Norn-Iridium-Composer — User Stories

## Session participant — operator

**S1.** I can type, select, complete, recall, paste and undo Unicode in the actual session without losing a draft.

**S2.** I can choose and remember Enter or Alt-Enter while seeing the active policy and save outcome.

**S3.** My original prompt/dividers/full-width input and fast startup stay intact while a turn runs.
