# Norn-Retained-Tui — User Stories

## Session participant — human operator or observing model

**S1.** As a session participant I can distinguish committed, provisional and incomplete history, and inspect the exact recorded body without affecting execution.

**S2.** As a participant I can keep reading a compact conversation and exact call changes while the terminal resizes and work continues.

**S3.** As a keyboard or mouse reader I can find, select, copy and export content and retain all current controls, with real terminal proof.
