# Norn-Frontend-Preferences — User Stories

## Session participant — operator

**S1.** My saved view choices do not erase MCP changes or pretend a published write never occurred.

**S2.** My current view choices can be remembered for myself or this project and restored after restart, with their active and saved scope clear.

**S3.** Saving or loading preferences preserves normal startup, appearance and ongoing interaction without launching extra services.
