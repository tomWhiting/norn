### R3: Optional default negotiation with strict named selection

Separate source selection from McpChannelPolicy. McpChannelSourcePolicy Off|Delivery(policy); settings constructor takes limits, default source policy, named overrides, overflow. Default resolves IfAdvertised, explicit delivery Required. Preserve listener ordering, retirement, approval and reload generation fencing.

**Acceptance:**
- Real stdio optional absent capability keeps tools; default capable server retains early notification; named off is tools-only.
- Explicit missing and malformed capabilities fail. Unknown/disabled/HTTP named delivery fails; default HTTP remains tools-only.
- No policy mutation on reload; no new subprocess or provider work for discovery.
- A default-selected ordinary server that declares no channel capability then fails tools/list is visibly unavailable without discarding a healthy channel source. Explicit named source failure remains fatal. Malformed capability refuses its source connection, with no admitted channel input.
