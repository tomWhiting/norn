# Norn-Channel-Settings — User Stories

## Norn operator — operator

**S1.** As an operator, I can save partial channel settings and combine them predictably.

**S2.** As an operator, I can override saved policy at launch without repeating every flag.

**S3.** As an operator, I can use channel-capable servers alongside ordinary MCP tools.

**S4.** As an operator, I can rely on the same policy in interactive and driven launches.

**S5.** As an operator, I can see what is installed and what remains under verification.
