# Norn-Channels — User Stories

## Norn operator — Collaborating with external systems

**S1.** As an operator, I want my existing conforming Channels MCP server to connect to Norn and retain its first pushed message.

**S2.** As an operator, I want explicit inbox policy and bounded retained work without stalling tool replies or confusing source identity.

**S3.** As a Rust server author, I want a real stdio fixture proving the public contract without JavaScript.

**S4.** As an operator, I want busy and idle running sessions to receive messages through their existing owned lifecycle.

**S5.** As an operator, I want to see enabled sources, pending inbox messages and refusals and change admission through existing controls.

**S6.** As an operator, I want Cambium and Hammerbarn interoperability demonstrated without unearned delivery guarantees.
